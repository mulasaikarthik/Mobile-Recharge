# 📱 Mobile Recharge System

A simple **Mobile Recharge System built with Python**.
This project allows users to enter a mobile number, select a recharge plan, and view the recharge details.

## 🚀 Features

* 📱 Enter a mobile number
* 💰 Choose from different recharge plans
* 📊 Display the selected data plan
* ✅ Validate the selected plan
* 🧩 Uses a custom Python function
* 🖥️ Simple command-line interface

## 📋 Available Plans

| Plan   | Price | Data       |
| ------ | ----: | ---------- |
| Plan 1 |  ₹199 | 1.5 GB/day |
| Plan 2 |  ₹299 | 2 GB/day   |
| Plan 3 |  ₹399 | 2.5 GB/day |
| Plan 4 |  ₹499 | 3 GB/day   |

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd mobile-recharge-system
```

### 3. Run the Python program

```bash
python mobile_recharge.py
```
